# Security Questionnaire — Standard Answers

Pilot and Enterprise customers will send their own security
questionnaire; keep this as a maintained set of standard answers to the
categories those questionnaires typically cover, cross-referenced to the
actual policy docs so answers can't drift from what's actually
implemented.

| Category | Standard answer source |
|---|---|
| Data encryption | [../03-security/encryption-policy.md](../03-security/encryption-policy.md) |
| Access control / RBAC | [../03-security/access-control-policy.md](../03-security/access-control-policy.md) |
| Tenant isolation | [../03-security/access-control-policy.md](../03-security/access-control-policy.md) |
| Incident response | [../03-security/incident-response-plan.md](../03-security/incident-response-plan.md) |
| Data retention / deletion | [../04-privacy/data-retention-policy.md](../04-privacy/data-retention-policy.md), [../04-privacy/deletion-policy.md](../04-privacy/deletion-policy.md) |
| Subprocessors | [subprocessors.md](./subprocessors.md) |
| Backup / DR | [../07-operations/disaster-recovery.md](../07-operations/disaster-recovery.md) |
| AI usage / model training | [../06-ai/ai-policy.md](../06-ai/ai-policy.md), [../05-legal/ai-terms.md](../05-legal/ai-terms.md) |
| Compliance certifications | [compliance-matrix.md](./compliance-matrix.md) — do not overstate uncertified status |

Do not answer any question with a certification or compliance claim
(SOC 2, ISO 27001, DPDP) that isn't actually true yet — pilots will find
out, and it's worse for trust than an honest "in progress, targeted for
[date]."
