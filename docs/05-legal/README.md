# Legal Documentation — Clause Checklists

**None of the files in this folder are drafted, binding legal text.**
They are checklists of clauses each document needs to cover, populated
with the product facts this PRD set already establishes (retention
periods, data handling, AI usage) so legal counsel isn't starting from a
blank page. Every file must go through qualified legal review before use
— Mistake handles customers' financial records, and getting liability,
indemnification, and data-processing terms wrong has real consequences
that a product document shouldn't attempt to resolve unilaterally.
